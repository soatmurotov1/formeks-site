# FOMEKS QOLDIQ — UzQoldiq.uz

Vite bilan ishlaydigan oddiy (vanilla JS) sayt.

- `index.html` — sahifa tuzilishi
- `src/style.css` — uslublar
- `src/main.js` — sayt mantig'i
- `public/data.js` — ma'lumotlar (`window.__FOMEKS_DATA__`, rasmlar base64 ko'rinishida)

## Ishga tushirish

```bash
npm install
npm run dev
```

Yig'ish: `npm run build` (natija `dist/` papkada).
